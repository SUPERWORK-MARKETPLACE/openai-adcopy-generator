# 대화 맥락 확장

## 확장 축 (조합해서 맥락 후보를 만든다)

`SKU × Persona × 고객 문제 × 상황 × 구매 여정·의도 × 메시지 방향`

**확장 절차 — 열거 → 격자 → 필터 (대각선만 켜지 마라):**
1. **축 값 전수 열거:** 입력에서 SKU·Persona·문제·상황·메시지 각도 값을 빠짐없이 뽑는다(브리프 타깃·니즈·혜택, 고객질문, 주력 키워드 근거).
2. **격자 전개 — 동일 SKU를 적용 가능한 모든 퍼널 단계로 펼친다.** 같은 상품도 ②발견·③비교·④평가·⑥사용 단계에서 질문·메시지 초점이 달라 **서로 다른 맥락**이 된다. 이 SKU×단계 전개가 **중복 없는 확장의 1차 레버** — 상품 하나당 한 단계씩만 켜는 대각선 생성을 피한다.
3. **자연스러움 필터:** 상품이 **자연스러운 해결책이 되는 칸만** 남긴다. 각 칸의 카피는 **그 단계의 질문에 답해야** 한다 — 단계만 바꾸고 제품 설명을 반복하면 근사 중복이다.

- 축이 부족하면 요청 수량보다 적게 출력한다(제외 사유 표시). 같은 의미의 문구 반복 생성 금지 — **수량보다 품질**. 격자를 넓혀도 카피 수의 상한은 **브리프가 준 사실의 개수**이며, 사실이 얇으면 입력 보강을 요청한다.

## 구매 여정 퍼널 6단계 (생성·분류의 핵심 축)

`①문제 정의 → ②제품 발견 → ③비교 검토 → ④단일 제품 평가 → ⑤구매·신청 → ⑥사용·문제 해결`

- 동일 상품도 단계별로 질문 맥락·메시지 초점을 달리해 생성한다 (예: 비교 검토 단계 → "생활비 카드 비교" 힌트, 비교 기준·혜택 차이 중심 카피).
- Context Hints는 각 단계에서 사용자가 **실제 입력할 법한 질문·고민·상황**으로, 제목·카피는 해당 단계의 **정보 요구 수준**에 맞춘다.
- 전 단계 동일 수량 금지 — 캠페인 목적·상품 특성에 따라 비중 조정(운영자 설정 우선). ⑥은 선택 적용.
- 퍼널 단계는 구매 가능성 단정이 아니라 **질문 목적·대화 맥락의 분류 기준**이다. 비교·평가 단계에서 경쟁사 비방·확인되지 않은 우월성/비교 표현 금지.

## 광고그룹 판단 흐름

입력 정보(SKU·Persona·상황) → 구매 여정(단계·세부 의도) → 운영 조건(랜딩·정책·입찰) → 그룹 결정:
- 구매 여정 단계·세부 의도가 유사하면 **묶는다**.
- 메시지 방향·Context Hints·랜딩 연결을 동일하게 운영하기 어려우면 **나눈다**.
- 여정 단계가 달라도 메시지 방향·랜딩·정책 조건을 동일하게 운영할 수 있으면 같은 그룹 가능.
- 캠페인 목적·국가/지역·예산/기간이 다르면 광고그룹이 아니라 **캠페인 분리** 사안 — 운영자에게 보고.
- `adgroup_name` 형식: `상품·SKU_고객유형_상황/문제_의도/메시지` 요소를 반영, 3~1,000자, 특수문자 가능, 중복 시 순번.

## Context Hints 생성 기준

- 광고그룹당 **5~10개 이상**. 단, 수량을 채우려 관련성 낮은 힌트를 만들지 마라.
- **힌트 수는 카피 수를 늘리지 않는다** — 힌트는 그룹의 매칭 표면(광고가 뜰 대화 범위)일 뿐이고, 카피 수는 축·사실이 정한다. 힌트를 채우려 카피를 만들지 마라.
- 유형 혼합: 구매 여정 유형(문제 정의형/제품 발견형/비교 검토형/단일 제품 평가형/구매·신청형/사용·문제 해결형) × 표현 형식(주제형/질문형/문제형/상황형).
- 정확 일치 키워드가 아니라 **문맥 매칭용 입력값** — 사용자가 ChatGPT에 실제로 쓸 문장에 가깝게.
- 실제 고객 데이터(FAQ·상담·검색어)에서 추출한 힌트는 `origin: "customer_data"`, AI 추론은 `origin: "ai_inferred"`.
- 경쟁사명만 포함되거나 자사 상품과 해결 연관성 없는 힌트는 제거.
