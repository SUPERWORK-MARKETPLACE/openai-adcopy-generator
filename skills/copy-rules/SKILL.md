# 제목·카피 작성 규칙

## 형식 (validate가 기계 검증 — 생성 시점부터 준수)

- `title`: 권장 16~18자, 최대 24자. 상품명만 반복 금지.
- `copy`: 권장 32~36자, 최대 48자. 제목·동일 혜택 반복 금지.
- 글자수는 공백 포함 문자(rune) 기준.

## 사실성 (환각 금지 — 최우선)

- **제공된 사실 안에서만** 생성한다. 미제공 혜택·조건·수치를 지어내지 마라.
- 수치·가격·기간은 랜딩페이지와 **정확히 일치**해야 한다.
- 출처 우선순위(충돌 시 상위 우선): ①법무·심의·정책 → ②광고주 브리프 → ③대표 랜딩 URL → ④소재별 랜딩 URL·이미지 내 문구 → ⑤고객 질문·검색 데이터 → ⑥AI 추론.
- 정보가 출처 간 충돌하면 생성하지 말고 `광고주 확인 필요`로 표시.
- 모든 생성물의 `trace`에 출처(`source_type`·`source_url`·`source_excerpt`)와 `generation_basis`(SKU·Persona·문제·상황·퍼널 단계·세부 의도·메시지 방향)를 기록 — 퍼널 단계 값은 6개 고정 토큰(문제정의·제품발견·비교검토·단일제품평가·신청전환·사용도움)만 쓴다. 근거가 없으면 `validation_status: "근거 확인 필요"`.
- **ai_inferred는 맥락 추론 전용이다** — 고객의 고민·상황·질문(대화 맥락)을 추론할 때만 쓴다. **상품 기능·측정 지표·수치·제3자 사용/도입·인증·수상 등 상품에 대한 사실 주장을 ai_inferred로 만들지 마라**(예: 입력 자료에 없는 "CEFR·Lexile 지수 진단", "전문 학원에서도 사용" — 실제 발생 사례). 그런 주장은 브리프·랜딩·이미지에 근거가 있을 때만 쓰고, 근거가 애매하면 생성하지 않거나 `validation_status: "근거 확인 필요"`를 반드시 남긴다.
- **근거 승격 금지(4차 실측 — 환각의 세부 유형)**: 근거 발췌가 사실을 **나열**만 하는데 copy가 이를 **인과·수단·조건 관계로 결합**하지 마라. 나쁨: 발췌 "무료체험 시 레벨테스트, 학습 데이터 확인, 맞춤 상담 가능"(나열) → copy "학습 데이터를 **바탕으로** 실력을 **객관적으로** 진단해요"(데이터→진단 인과 결합 + 근거에 없는 정도 부사). 단어가 전부 근거에 있어도 **관계와 정도는 별도 근거가 필요**하다. "바탕으로·통해·기반으로·덕분에" 같은 연결어와 "객관적으로·정확히·완벽히" 같은 강화 부사를 쓸 때마다 발췌에 그 관계·정도가 실제로 있는지 확인 — 없으면 나열 수준으로 낮춰 쓰거나 `근거 확인 필요` 플래그.
- 근거를 인용한 광고(`source_type`이 ai_inferred가 아닌 광고)는 **`source_excerpt`에 근거 원문 발췌를 반드시 기록**한다 — 빈칸이면 validate가 `source_excerpt_missing`으로 경고(ads에 적용; `source_type` 자체가 빈칸이면 검사 대상 아님 — 출처가 아예 없으면 `근거 확인 필요` 플래그로 처리).

## 카피 핵심 반영 요소·이용조건 고지

- **카피 핵심 반영 요소(생성 가이드 — 기계 검사 아님)**: 상품·브리프의 "카피 핵심 반영 요소"는 그 SKU의 혜택·조건·특징 키워드/짧은 구문 **후보군**이다(`/` 구분, 예: "무료학습 체험 / 아이 영어 수준 진단 / 체험 후 결정"). **반드시 포함이 아니다** — 광고별로 상황·퍼널 단계에 맞는 **1~2개를 선택해 재구성**한다. 그대로 옮길 의무 없음, **동등 의미 표현 허용**. 후보군 전체를 한 카피에 몰아넣지 마라.
- **선택·기록**: 사용한 요소를 `trace.generation_basis`에 `핵심요소=...`로 남긴다. 같은 광고그룹 안에서는 광고마다 선택 요소·표현을 달리해 단조로움을 피한다(모든 카피가 같은 요소·같은 어미로 끝나면 안 된다).
- **자체 점검(의미 검수)**: 각 광고의 title+copy가 선택한 요소를 실제로 반영했는지, 후보군·브리프에 없는 혜택을 지어내지 않았는지 확인한다(사실성 규칙과 동일선상). 요소를 하나도 반영하지 못한 광고는 `validation_status`에 사유를 남긴다.
- **이용조건 고지(금융 필수 고지)**: 혜택만 강조하지 말고 **주요 이용 조건**(전월 이용실적·발급 심사·연회비·할인 한도·혜택 대상 가맹점·해외 이용 수수료 등)을 함께 표기한다. 조건을 감춘 혜택 단정은 금지. 고지문을 title에 넣지 마라(고지문이 헤드라인이 되면 훅이 죽는다).

## 금지 규칙

- **경쟁사명·비교 표현**: 경쟁사명 기본 제외 — 광고주가 입력했어도 자동 사용 금지, 승인된 허용 목록에 있을 때만. 비교 표현은 **정책이 제한적 허용이면 카테고리·혜택 비교까지만** 가능하고(예: "생활비 혜택 카드 비교"), **경쟁사명·확인되지 않은 우월성 단정은 금지**.
- **개인정보**: 상담·챗봇 데이터의 이름/전화번호/이메일/카드번호는 비식별화. 카피에 개인 식별 정보 사용 금지.
- **민감 주제**: 금융·건강 등 개인 상태를 추정하는 표현 금지 (예: "빚 때문에 힘드시죠" 유형).
- **정책·금지어(기계 검사)**: 입력 정책 시트의 **공통 금지 표현 + SKU별 금지 표현**을 생성 시점부터 그대로 회피한다(예: "무조건 발급"·"누구나"·"최고"·"반드시 절약"·"혜택 보장"·"업계 1위"). 이 목록은 generated.json 최상위 `policy.banned_terms`로 병합되고, validate가 `banned_term` 규칙으로 title·copy·Context Hints를 기계 검사한다.
- **프로모션 종료**: 종료일 지난 소재 관련 문구 생성 금지.

## 문장 자연성 (S4)

- **title (관대)**: 짧은 구문형·질문형·명사형 종결을 허용한다. 단 의미 검수에서 다음은 플래그한다 — 의미가 끊기는 문구 / 조사·목적어 누락으로 어색한 문구 / 부자연스러운 단어 조합 / 광고 메시지가 직관적으로 전달되지 않는 문구.
- **copy (엄격)**: **완결된 자연스러운 한국어 문장**만 허용한다 — 명사구 종결 금지, 조건절 종결(`~면` 끝) 금지, 길고 설명문 같은 부자연 문장 금지. 어색한 표현·주어/목적어/수식어 연결이 어색한 문장도 플래그. **copy는 title보다 문장 완성도를 더 엄격하게 점검한다**(0715 요청 2).
- **copy 자연성 anti-pattern(0715 실사례 — 생성 시 회피, 발견 시 재작성)**:
  - **설명문투·딱딱한 광고 톤**: 문법은 맞지만 건조한 서술 — 사용자(아이·학부모)가 얻는 효과가 문장의 중심에 오게 쓴다. 나쁨: "폭슬리가 먼저 영어로 말을 걸어주니 대화를 편하게 시작합니다" → 개선: "먼저 말 걸어주는 폭슬리 덕분에 아이도 부담 없이 영어로 대답해요" / 나쁨: "매달 학원비를 들이기 전에 합리적인 홈러닝을 먼저 따져봅니다"("따져봅니다"류 딱딱한 서술어) → 개선: "매달 나가는 학원비, 집에서 하는 홈러닝과 먼저 비교해 보세요".
  - **어색한 조사·어순·수식 연결**: 소리 내어 읽었을 때 걸리는 문장 금지. 나쁨: "하루 폭슬리에게 먼저 말을 걸면 매일 영어 대화가 습관이 되죠"("하루 폭슬리에게" — 조사·어순 어색) → 개선: "매일 폭슬리와 나누는 짧은 대화가 영어 습관으로 이어져요".
  - **길고 늘어지는 문장 구조**: 한 문장에 절을 겹겹이 쌓지 마라 — 짧고 리듬 있는 광고 문장으로.
  - **문어체·보고서체 서술어(4차 실측)**: "따져봅니다"뿐 아니라 **견주다·도모하다·꾀하다·영위하다** 류 책상물림 서술어 금지 — 학부모가 일상에서 쓰는 말로(비교해 보세요·살펴보세요·확인할 수 있어요). 나쁨: "홈러닝과 비용을 **견주면** 선택이 쉬워져요" → 개선: "홈러닝과 비용을 **비교해 보면** 선택이 쉬워져요". 같은 특이 서술어를 **여러 광고그룹에서 반복하지 마라**(4차 실측: '견주다' 3개 그룹 반복 — 전역 점검은 pipeline 의미 검수·§8-4).
  - **명사 적층(4차 실측)**: 조사 없이 명사 3개 이상 연속 금지. 나쁨: "집에서 **학원 커리큘럼 홈러닝을** 무료학습으로 먼저 겪어보면 좋아요" → 개선: "학원식 커리큘럼 홈러닝, 무료학습으로 먼저 경험해 보세요".
  - **연어(collocation) 점검(4차 실측)**: 동사가 목적어·주어와 표준 짝인지 확인. "실력이 늘다"(O)/"**실전이 안 늘죠**"(X) · 긍정 체험에 "겪다" 금지(부정 뉘앙스 — 경험하다·체험하다로) · "앱에서 볼 수 있어요"(O)/"**부모에게 보여요**"(X 어색).
  - **어미 부조화(4차 실측)**: 제안·권유로 시작한 문장은 제안형으로 끝낸다. 나쁨: "혼자 애쓰지 **말고** … 살펴볼 수 **있죠**"(권유 시작 + 단정 종결) → 개선: "혼자 애쓰지 말고 무료학습으로 아이 수준을 살펴**보세요**".
  - 셀프 체크: 생성한 copy를 한국어 화자가 소리 내어 읽는다고 가정하고, 어색하면 그 자리에서 재작성한다.
- **기계 검사 `copy_sentence_form`(warning, 한국어 copy만)**: `?`/`!` 종결이거나 꼬리 구두점 제거 후 `요`/`다`/`까`/`죠`로 끝나야 통과 — `면` 종결은 조건절 경고, 그 외는 명사구·불완전 종결 경고. 생성 시점부터 이 형태로 쓴다. (자연성의 나머지 — 설명문투·어색한 연결 — 는 기계가 못 잡으므로 위 anti-pattern 셀프 체크가 1차 방어선이다.)
- **어체 통일**: copy는 **해요체 또는 합니다체**로 쓴다 — 반말 평서형 종결(`…있다`/`…된다`/`…한다`) 금지(기계 검사 `copy_speech_level`, warning). 같은 광고그룹 안에서도 어체가 튀지 않게 유지한다.
- 자연성 문제를 발견하면 `validation_status`에 **"문장 자연성 확인 필요"**를 기록한다.

## title+copy 연결성 (S5)

- title과 copy는 독립 문구가 아니라 **하나의 광고 메시지 세트**다. 함께 읽었을 때 **고민/질문 제기(title) → 해결 방향 제시(copy)** 구조가 되어야 한다(0715 요청 2).
- **title = 훅**: 사용자의 고민·상황·질문·관심을 짧게 잡는다.
- **copy = 보완**: title의 맥락을 이어받아 **구체 해결 방향·혜택·이용 방식·확인 포인트**를 채운다. **title 핵심어 단순 반복 금지** — 반복이면 `validation_status`에 "의미 중복 후보"를 플래그하고 재작성한다(AI 셀프 체크).
- **title 어절 재배열 금지**: copy가 title의 어절을 그대로 이어받아 재배열·부연만 하면 새 정보가 없다 — validate가 `title_copy_overlap`(문자 중복률 기반)으로 경고.
- **고민 반복 금지(0715)**: title이 제기한 고민을 copy가 다른 말로 반복만 하고 해결 방향을 주지 않으면 금지. 나쁨: T "집에서 영어 습관 잡기 어렵다면" / C "학원 없이 집에서 매일 영어 공부를 이어가기가 쉽지 않아요" — copy에 해결이 없다. **이 유형은 기계 검사가 못 잡는다**(어절이 달라 `title_copy_overlap` 침묵) — 의미 검수 셀프 체크가 유일한 방어선이며, 발견 시 `validation_status`에 "의미 중복 후보"를 플래그하고 재작성한다.
- **재질문 금지(0715, 기계 검사 `title_copy_question_repeat`, warning)**: title이 질문인데 copy도 질문으로 끝나면 세트가 답을 주지 못한다. 나쁨: T "영어학원비 매달 부담되시나요?" / C "매달 나가는 학원비, 집에서 줄일 방법이 궁금하지 않으세요?" / 나쁨: T "온라인 영어학습 무엇이 다를까요?" / C "학원과 홈스쿨링, 온라인 학습을 두루 비교해보고 싶으시죠?" — copy는 해결 방향·혜택·이용 방식으로 **답한다**.
- 연결 예시:

| title (훅) | copy (보완) |
|---|---|
| 인터넷 새로 하면 얼마나 아낄까? | 통신사별 요금·지원금을 비교해 가장 유리한 조합을 찾아드려요. |
| 초등 영어, 단계별 학습 지도 | 파닉스 이후 문법·독해·말하기 순서를 잡아줘요 |
| 집에서 하는 영어, 무료 시작 | 신청 후 7일간 주요 콘텐츠를 먼저 경험할 수 있어요 |

- 나쁜 예(어절 재배열 — `title_copy_overlap` 경고): T "학부모 앱으로 보는 학습 데이터" / C "학부모 앱으로 아이의 학습 데이터를 직접 확인해볼 수 있다" → 개선: C "아이가 오늘 얼마나 학습했는지 앱에서 바로 확인할 수 있어요"

## 메시지 다양성

- 같은 광고그룹 안에서도 카피는 서로 다른 메시지 각도(혜택/신뢰/공감/방법 제시 등)를 다뤄야 한다.
- **문장 형식 혼합**: 질문형/공감형/정보형/혜택형/비교형을 섞는다 — 동일 광고그룹에서 한 형식만 반복 금지. 단, **질문형 copy는 title이 질문형이 아닐 때만** 쓴다(§title+copy 연결성 재질문 금지).
- **종결 형태 분산**: title은 질문형/명사형/조건형/공감형 등, copy는 **완결 문장 범위 안에서** 질문형/정보형/제안형/비교형/행동유도형/공감형 등으로 나눈다 — **명사형·조건형 종결은 title 전용**, copy에 쓰지 마라(§문장 자연성). `~하세요/~해보세요/~확인하세요/~합니다/~있습니다` 형태 과다 반복 금지.
- **CTA형 종결 30% 이하(기계 검사)**: 사용자 행동을 직접 유도하는 종결(확인해보세요·신청하세요·시작해보세요·비교해보세요·알아보세요 등)은 동일 광고그룹 카피의 **30% 이하** — validate가 `copy_cta_ratio_30` 규칙으로 경고를 낸다.
- title 종결 형태 예시 (구문형·명사형·조건형 허용):

| 종결 형태 | 예시 |
|---|---|
| 질문형 | 초등 영어, 어디서 시작해야 할까요? |
| 명사형 | 집에서 시작하는 초등 영어 루틴 |
| 조건형 | 아이 영어 수준이 궁금하다면 |
| 공감형 | 영어 시작이 막막한 부모님에게 |
| 결과형 | 매일 쌓이는 영어 학습 습관 |

- copy 종결 형태 예시 (전부 완결 문장형 — 명사구·조건절 종결 금지):

| 종결 형태 | 예시 |
|---|---|
| 질문형 | 아이 영어, 무료 레벨테스트로 시작해 볼까요? |
| 정보형 | 무료 레벨테스트로 아이 수준을 먼저 진단할 수 있어요 |
| 제안형 | 학원 대신 집에서 하는 홈러닝도 좋은 선택지예요 |
| 비교형 | 학원과 온라인 학습의 차이를 한눈에 비교해 드려요 |
| 행동유도형 | 아이에게 맞는 학습법을 확인해보세요 |
| 공감형 | 막막했던 영어 시작, 수준 진단부터 함께 잡아드려요 |

- Context Hints를 충분히 커버하도록 제목·카피 세트를 구성한다.
- 목표 수량을 채우려 동일 의미 문구를 **무표시로** 반복하지 마라. 확장 축이 목표에 못 미치면(pipeline §8-1 워닝) 초과분은 **명시적 로테이션 변형**으로 생성한다 — `generation_basis`에 `변형=로테이션`을 남기고 의미 중복 후보 검토의 우선 대상이 된다.
