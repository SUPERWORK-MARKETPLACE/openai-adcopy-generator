# 제목·카피 작성 규칙

## 형식 (validate가 기계 검증 — 생성 시점부터 준수)

- `title`: 권장 16~18자, 최대 24자. 상품명만 반복 금지.
- `copy`: 권장 32~36자, 최대 48자. 제목·동일 혜택 반복 금지.
- 글자수는 공백 포함 문자(rune) 기준.

## 사실성 (환각 금지 — 최우선)

- **제공된 사실 안에서만** 생성한다. 미제공 혜택·조건·수치를 지어내지 마라.
- 수치·가격·기간은 랜딩페이지와 **정확히 일치**해야 한다.
- 출처 우선순위(충돌 시 상위 우선): ①법무·심의·정책 → ②광고주 브리프 → ③대표 랜딩 URL → ④소재별 랜딩 URL·이미지 내 문구 → ⑤고객 질문·검색 데이터 → ⑥AI 추론.
- 정보가 출처 간 충돌하면 생성하지 말고 `광고주 확인 필요`로 표시.
- 모든 생성물의 `trace`에 출처(`source_type`·`source_url`·`source_excerpt`)와 `generation_basis`(SKU·Persona·문제·상황·퍼널 단계·세부 의도·메시지 방향)를 기록 — 퍼널 단계 값은 6개 고정 토큰(문제정의·제품발견·비교검토·단일제품평가·신청전환·사용도움)만 쓴다(`퍼널=` 누락·토큰 위반은 경고 `generation_basis_funnel_missing`·`generation_basis_funnel_token`, `adgroup_name`의 여정 슬롯 위반은 **오류** `adgroup_name_funnel_token`). 근거가 없으면 `validation_status: "근거 확인 필요"`.
- **ai_inferred는 맥락 추론 전용이다** — 고객의 고민·상황·질문(대화 맥락)을 추론할 때만 쓴다. **상품 기능·측정 지표·수치·제3자 사용/도입·인증·수상 등 상품에 대한 사실 주장을 ai_inferred로 만들지 마라**(예: 입력 자료에 없는 "CEFR·Lexile 지수 진단", "전문 학원에서도 사용" — 실제 발생 사례). 그런 주장은 브리프·랜딩·이미지에 근거가 있을 때만 쓰고, 근거가 애매하면 생성하지 않거나 `validation_status: "근거 확인 필요"`를 반드시 남긴다.
- **근거 승격 금지(4차 실측 — 환각의 세부 유형)**: 근거 발췌가 사실을 **나열**만 하는데 copy가 이를 **인과·수단·조건 관계로 결합**하지 마라. 나쁨: 발췌 "무료체험 시 레벨테스트, 학습 데이터 확인, 맞춤 상담 가능"(나열) → copy "학습 데이터를 **바탕으로** 실력을 **객관적으로** 진단해요"(데이터→진단 인과 결합 + 근거에 없는 정도 부사). 단어가 전부 근거에 있어도 **관계와 정도는 별도 근거가 필요**하다. "바탕으로·통해·기반으로·덕분에" 같은 연결어와 "객관적으로·정확히·완벽히" 같은 강화 부사를 쓸 때마다 발췌에 그 관계·정도가 실제로 있는지 확인 — 없으면 나열 수준으로 낮춰 쓰거나 `근거 확인 필요` 플래그.
- 근거를 인용한 광고(`source_type`이 ai_inferred가 아닌 광고)는 **`source_excerpt`에 근거 원문 발췌를 반드시 기록**한다 — 빈칸이면 validate가 `source_excerpt_missing`으로 경고(ads에 적용; `source_type` 자체가 빈칸이면 검사 대상 아님 — 출처가 아예 없으면 `근거 확인 필요` 플래그로 처리).

## 카피 핵심 반영 요소·이용조건 고지

- **카피 핵심 반영 요소(생성 가이드 — 기계 검사 아님)**: 상품·브리프의 "카피 핵심 반영 요소"는 그 SKU의 혜택·조건·특징 키워드/짧은 구문 **후보군**이다(`/` 구분, 예: "무료학습 체험 / 아이 영어 수준 진단 / 체험 후 결정"). **반드시 포함이 아니다** — 광고별로 상황·퍼널 단계에 맞는 **1~2개를 선택해 재구성**한다. 그대로 옮길 의무 없음, **동등 의미 표현 허용**. 후보군 전체를 한 카피에 몰아넣지 마라.
- **선택·기록**: 사용한 요소를 `trace.generation_basis`에 `핵심요소=...`로 남긴다. 같은 광고그룹 안에서는 광고마다 선택 요소·표현을 달리해 단조로움을 피한다(모든 카피가 같은 요소·같은 어미로 끝나면 안 된다).
- **자체 점검(의미 검수)**: 각 광고의 title+copy가 선택한 요소를 실제로 반영했는지, 후보군·브리프에 없는 혜택을 지어내지 않았는지 확인한다(사실성 규칙과 동일선상). 요소를 하나도 반영하지 못한 광고는 `validation_status`에 사유를 남긴다.
- **이용조건 고지(금융 필수 고지)**: 혜택만 강조하지 말고 **주요 이용 조건**(전월 이용실적·발급 심사·연회비·할인 한도·혜택 대상 가맹점·해외 이용 수수료 등)을 함께 표기한다. 조건을 감춘 혜택 단정은 금지. 고지문을 title에 넣지 마라(고지문이 헤드라인이 되면 훅이 죽는다).

## 금지 규칙

- **경쟁사명·비교 표현**: 경쟁사명 기본 제외 — 광고주가 입력했어도 자동 사용 금지, 승인된 허용 목록에 있을 때만. 비교 표현은 **정책이 제한적 허용이면 카테고리·혜택 비교까지만** 가능하고(예: "생활비 혜택 카드 비교"), **경쟁사명·확인되지 않은 우월성 단정은 금지**.
- **개인정보**: 상담·챗봇 데이터의 이름/전화번호/이메일/카드번호는 비식별화. 카피에 개인 식별 정보 사용 금지.
- **민감 주제**: 금융·건강 등 개인 상태를 추정하는 표현 금지 (예: "빚 때문에 힘드시죠" 유형).
- **정책·금지어(기계 검사)**: 입력 정책 시트의 **공통 금지 표현 + SKU별 금지 표현**을 생성 시점부터 그대로 회피한다(예: "무조건 발급"·"누구나"·"최고"·"반드시 절약"·"혜택 보장"·"업계 1위"). 이 목록은 generated.json 최상위 `policy.banned_terms`로 병합되고, validate가 `banned_term` 규칙으로 title·copy·Context Hints를 기계 검사한다.
- **프로모션 종료**: 종료일 지난 소재 관련 문구 생성 금지.

## 문장 자연성 (S4 — 원칙이 우선, 예시 목록은 보정용)

**대원칙: 카피는 규칙을 채운 문장이 아니라 사람이 실제로 하는 말이어야 한다.** 어떤
광고주·어떤 상품이 와도 그대로 적용되는 일반 검사 3가지 — 모든 title·copy에 문장 단위로
적용하고, 하나라도 걸리면 재작성한다(규칙을 다 지켰다는 것은 면죄부가 아니다):

1. **입말 테스트**: 이 문장을 고객에게 얼굴 보고 직접 말한다고 상상하라. 평소 한국어에서
   그렇게 말하지 않는 부분이 하나라도 있으면 "평소라면 뭐라고 말하지?"를 떠올려 그 형태로
   다시 쓴다. 광고 카피라는 이유로 말이 안 되는 문장이 허용되지 않는다.
2. **처음 보는 조합 의심**: 동사–목적어, 명사–명사 연쇄가 실제 한국어 글·대화에서 쓰이는
   조합인지 자문하라. **카피를 쓰다가 새로 만든 조합은 대부분 어색하다** — 확신이 없으면
   흔히 쓰는 표현으로 바꾼다(연어 파괴·명사 적층이 전형).
3. **압축은 내용으로, 문법으로 하지 마라**: 글자수를 맞추려고 조사·목적어·필수 성분을
   깎지 마라. 어색한 카피의 상당수가 길이 압축의 부산물이다(실측: "정회원 **가입 여부를**
   정하다"에서 '가입 여부'를 깎아 "정회원을 정하다"). 길이가 넘치면 **정보 요소를 하나 빼고
   문장을 처음부터 다시 설계**한다.

- **title (관대)**: 짧은 구문형·질문형·명사형 종결을 허용한다. 단 의미 검수에서 다음은 플래그한다 — 의미가 끊기는 문구 / 조사·목적어 누락으로 어색한 문구 / 부자연스러운 단어 조합 / 광고 메시지가 직관적으로 전달되지 않는 문구.
- **copy (엄격)**: **완결된 자연스러운 한국어 문장**만 허용한다 — 명사구 종결 금지, 조건절 종결(`~면` 끝) 금지, 길고 설명문 같은 부자연 문장 금지. 어색한 표현·주어/목적어/수식어 연결이 어색한 문장도 플래그. **copy는 title보다 문장 완성도를 더 엄격하게 점검한다**(0715 요청 2).
- **copy 자연성 anti-pattern(실측 사례 — 열거가 아니라 예시다)**: 아래는 위 3원칙에 걸렸던 실제 사례의 유형화다. **목록에 없어도 3원칙에 걸리면 같은 취급**이며, 특정 어휘 목록 암기가 아니라 원칙 적용이 본질이다:
  - **설명문투·딱딱한 광고 톤**: 문법은 맞지만 건조한 서술 — 사용자(아이·학부모)가 얻는 효과가 문장의 중심에 오게 쓴다. 나쁨: "폭슬리가 먼저 영어로 말을 걸어주니 대화를 편하게 시작합니다" → 개선: "먼저 말 걸어주는 폭슬리 덕분에 아이도 부담 없이 영어로 대답해요" / 나쁨: "매달 학원비를 들이기 전에 합리적인 홈러닝을 먼저 따져봅니다"("따져봅니다"류 딱딱한 서술어) → 개선: "매달 나가는 학원비, 집에서 하는 홈러닝과 먼저 비교해 보세요".
  - **어색한 조사·어순·수식 연결**: 소리 내어 읽었을 때 걸리는 문장 금지. 나쁨: "하루 폭슬리에게 먼저 말을 걸면 매일 영어 대화가 습관이 되죠"("하루 폭슬리에게" — 조사·어순 어색) → 개선: "매일 폭슬리와 나누는 짧은 대화가 영어 습관으로 이어져요".
  - **길고 늘어지는 문장 구조**: 한 문장에 절을 겹겹이 쌓지 마라 — 짧고 리듬 있는 광고 문장으로.
  - **문어체·보고서체 서술어(4차 실측)**: "따져봅니다"뿐 아니라 **견주다·도모하다·꾀하다·영위하다** 류 책상물림 서술어 금지 — 학부모가 일상에서 쓰는 말로(비교해 보세요·살펴보세요·확인할 수 있어요). 나쁨: "홈러닝과 비용을 **견주면** 선택이 쉬워져요" → 개선: "홈러닝과 비용을 **비교해 보면** 선택이 쉬워져요". 같은 특이 서술어를 **여러 광고그룹에서 반복하지 마라**(4차 실측: '견주다' 3개 그룹 반복 — 전역 점검은 pipeline 의미 검수·§8-4).
  - **명사 적층(4차 실측)**: 조사 없이 명사 3개 이상 연속 금지. 나쁨: "집에서 **학원 커리큘럼 홈러닝을** 무료학습으로 먼저 겪어보면 좋아요" → 개선: "학원식 커리큘럼 홈러닝, 무료학습으로 먼저 경험해 보세요".
  - **연어(collocation) 점검(4차 실측)**: 동사가 목적어·주어와 표준 짝인지 확인. "실력이 늘다"(O)/"**실전이 안 늘죠**"(X) · 긍정 체험에 "겪다" 금지(부정 뉘앙스 — 경험하다·체험하다로) · "앱에서 볼 수 있어요"(O)/"**부모에게 보여요**"(X 어색) · "정회원 **가입을 결정**할 수 있어요"(O)/"**정회원을 정할** 수 있어요"(X — 결정 대상은 자격 명사가 아니라 가입·등록 **여부**다, 5차 실측).
  - **어미 부조화(4차 실측)**: 제안·권유로 시작한 문장은 제안형으로 끝낸다. 나쁨: "혼자 애쓰지 **말고** … 살펴볼 수 **있죠**"(권유 시작 + 단정 종결) → 개선: "혼자 애쓰지 말고 무료학습으로 아이 수준을 살펴**보세요**".
  - **화자 시점 튐(0720 실측)**: 카피는 **광고를 읽는 사람(타깃 페르소나) 시점으로 고정**한다 —
    구매자와 사용자가 다른 상품(키즈·시니어·선물류)에서 특히 주의. 나쁨: 학부모 타깃 카피에
    "원어민 발음과 **내 발음**을 나란히 비교해 볼 수 있어요"(읽는 사람은 학부모인데 화자가
    학습자) → 개선: "원어민 발음과 아이 발음을 나란히 비교해 줘요".
  - 셀프 체크: 3원칙은 **쓸 때의 기준**이다 — 문장별 별도 검증 루프를 돌리지 마라(시간 폭증). 점검은 **반환 직전 전체 재독 1회**로 끝내고, 그때 걸린 문장만 재작성한다. 재독 후에도 확신 없는 문장은 고치려 반복하지 말고 `문장 자연성 확인 필요`로 플래그해 검수로 넘긴다.
- **기계 검사 `copy_sentence_form`(warning, 한국어 copy만)**: `?`/`!` 종결이거나 꼬리 구두점 제거 후 `요`/`다`/`까`/`죠`로 끝나야 통과 — `면` 종결은 조건절 경고, 그 외는 명사구·불완전 종결 경고. 생성 시점부터 이 형태로 쓴다. (자연성의 나머지 — 설명문투·어색한 연결 — 는 기계가 못 잡으므로 위 anti-pattern 셀프 체크가 1차 방어선이다.)
- **어체 통일**: copy는 **해요체 또는 합니다체**로 쓴다 — 반말 평서형 종결(`…있다`/`…된다`/`…한다`) 금지(기계 검사 `copy_speech_level`, warning). 같은 광고그룹 안에서도 어체가 튀지 않게 유지한다.
- 자연성 문제를 발견하면 `validation_status`에 **"문장 자연성 확인 필요"**를 기록한다.

## title+copy 연결성 (S5)

- title과 copy는 독립 문구가 아니라 **하나의 광고 메시지 세트**다. 함께 읽었을 때 **고민/질문 제기(title) → 해결 방향 제시 → 혜택·판단 포인트 제공(copy)** 구조가 되어야 한다(0715 요청 2 · 0716 §광고 매력도).
- **title = 훅**: 사용자의 고민·상황·질문·관심을 짧게 잡는다.
- **copy = 보완**: title의 맥락을 이어받아 **구체 해결 방향·혜택·이용 방식·확인 포인트**를 채운다. **title 핵심어 단순 반복 금지** — 반복이면 `validation_status`에 "의미 중복 후보"를 플래그하고 재작성한다(AI 셀프 체크).
- **title 어절 재배열 금지**: copy가 title의 어절을 그대로 이어받아 재배열·부연만 하면 새 정보가 없다 — validate가 `title_copy_overlap`(문자 중복률 기반)으로 경고.
- **고민 반복 금지(0715)**: title이 제기한 고민을 copy가 다른 말로 반복만 하고 해결 방향을 주지 않으면 금지. 나쁨: T "집에서 영어 습관 잡기 어렵다면" / C "학원 없이 집에서 매일 영어 공부를 이어가기가 쉽지 않아요" — copy에 해결이 없다. **이 유형은 기계 검사가 못 잡는다**(어절이 달라 `title_copy_overlap` 침묵) — 의미 검수 셀프 체크가 유일한 방어선이며, 발견 시 `validation_status`에 "의미 중복 후보"를 플래그하고 재작성한다.
- **재질문 금지(0715, 기계 검사 `title_copy_question_repeat`, warning)**: title이 질문인데 copy도 질문으로 끝나면 세트가 답을 주지 못한다. 나쁨: T "영어학원비 매달 부담되시나요?" / C "매달 나가는 학원비, 집에서 줄일 방법이 궁금하지 않으세요?" / 나쁨: T "온라인 영어학습 무엇이 다를까요?" / C "학원과 홈스쿨링, 온라인 학습을 두루 비교해보고 싶으시죠?" — copy는 해결 방향·혜택·이용 방식으로 **답한다**.
- **고민 축 일치(0722 — 연결성의 적극 기준)**: copy가 해결·혜택을 제시하는 것만으로는 부족하다 —
  **title이 제기한 바로 그 고민 축**에서 답해야 한다. 아래 매핑은 예시 축이다(광고주·상품마다
  고민 축은 다르다) — 원칙은 하나: **copy의 해결·혜택이 title 고민과 같은 축에 있는가**를
  세트마다 확인한다.

| title 고민 축 (예시) | copy가 이어야 할 방향 |
|---|---|
| 비용 고민 | 비용 부담 완화, 지출 전에 판단할 수 있는 근거 |
| 시간 부족 | 시간 절감, 간편한 이용 방식 |
| 상태·수준 확인(실력·요금 수준 등) | 현재 상태 진단, 다음 단계 제시 |
| 비교 고민 | 선택 기준, 비교 포인트 |
| 관리 불안 | 관리 방식, 확인 가능한 요소 |
| 사용 부담 | 쉬운 시작, 체험, 사용 편의성 |

- **축 어긋남 금지(0722 실측)**: copy가 해결을 제시해도 title 고민과 **다른 축의 범용 해결**(그
  SKU의 대표 전환 장치 — 체험·상담·가입 안내 등)이면 연결 실패다. 나쁨: T "숙제 봐주다 지치는
  저녁이라면"(보호자 피로 축) / C "정회원과 같은 콘텐츠를 7일 동안 써보고 아이에게 맞는지
  판단해요"(일반 체험 안내 — 피로 축의 해결이 아니다) → 개선: 보호자가 매번 챙기지 않아도 되는
  학습 흐름·아이가 스스로 따라가는 구조·관리 가능성 등 **피로 축의 사실**로 답한다. 전환 장치가
  하나뿐인 상품일수록 모든 title에 같은 copy 각도를 붙이기 쉽다(0720 판단 축 배타 배정과 같은
  뿌리) — title 축에 맞는 사실을 입력에서 골라 연결하고, 그 축의 사실이 없으면 §광고 매력도의
  정보 공백 규칙대로 **각도를 전환하거나 그 title을 만들지 않는다**.
- **기능 나열 확산 금지(0722 실측)**: title이 구체 고민인데 copy가 상품 기능 **전체 나열**로
  넓어지면 실패다. 나쁨: T "배운 문장, 말할 땐 안 나오죠"(말하기 전환 고민) / C "단어와 발음,
  말하기까지 영어 4대 영역을 앱에서 하나씩 훈련해요"(기능 전체 나열 — 고민이 흐려진다) →
  개선: 배운 표현을 말로 꺼내는 연습·반복 말하기처럼 **title 고민에 맞는 기능 하나로 좁혀** 답한다.
- 연결 예시:

| title (훅) | copy (보완) |
|---|---|
| 인터넷 새로 하면 얼마나 아낄까? | 통신사별 요금·지원금을 비교해 가장 유리한 조합을 찾아드려요. |
| 초등 영어, 단계별 학습 지도 | 파닉스 이후 문법·독해·말하기 순서를 잡아줘요 |
| 집에서 하는 영어, 무료 시작 | 신청 후 7일간 주요 콘텐츠를 먼저 경험할 수 있어요 |

- 나쁜 예(어절 재배열 — `title_copy_overlap` 경고): T "학부모 앱으로 보는 학습 데이터" / C "학부모 앱으로 아이의 학습 데이터를 직접 확인해볼 수 있다" → 개선: C "아이가 오늘 얼마나 학습했는지 앱에서 바로 확인할 수 있어요"

## 광고 매력도 (0716 — 클릭 유도 기준)

**규칙을 다 지킨 안전한 문장이 좋은 카피가 아니다.** 자연성·연결성을 충족해도 설명형·정보형
문구는 광고로 노출됐을 때 클릭을 유도하지 못한다(0716 실측 지적). 광고주 불문 공통 적용 —
모든 title+copy 세트는 아래 구조로 만든다:

**사용자 고민 자극(title) → 해결 방향 제시 → 혜택 또는 판단 포인트 제공(copy)**

- **title은 사용자의 고민·질문·상황을 먼저 건드린다** — 단순 기능명·설명형 제목보다 우선. 피할 것:
  - 상품 기능을 그대로 설명하는 제목 (나쁨: "캐츠잉글리시 온라인 학습의 장점")
  - 리포트/안내문처럼 보이는 제목 (나쁨: "초중등 영어, 한눈에 보는 로드맵" · "온라인 영어학습, 시작 전 확인")
  - 사용자의 고민이나 궁금증이 약한 제목
  - **추상·과압축으로 의미가 흐린 제목(0722 실측)** — 처음 읽는 사용자가 무슨 이야기인지 바로
    이해하지 못하는 title(나쁨: "한 번 받은 결과, 계속 가나요?" — 무엇이 계속 간다는지 불명),
    광고 문구로 어색한 표현(나쁨: "영어에 쓰는 돈, 정하기 전에") — 바로 이해되는 고민형·질문형·
    상황형으로 조정한다. 자연성 3원칙 "압축은 내용으로"가 title에도 적용된다 — 글자수를 맞추려는
    과압축이 직관성을 죽인다.
  질문형만 정답이 아니다 — 조건형("영어학원비가 매달 부담된다면")·상황형("배운 단어, 며칠 뒤엔
  가물가물")도 고민을 건드리면 좋은 title이다(§메시지 다양성 종결 형태 분산과 병행).
- **copy는 title 맥락을 이어받아 사용자가 얻는 변화·혜택·판단 포인트를 드러낸다.** 피할 것:
  - 기능만 설명하는 문장
  - **정의·안내문형 종결(0722 실측)** — 상품이 "무엇인지"를 정의하거나 프로그램 구조를 설명하며
    끝나는 copy(나쁨: "온라인 학습은 학습기로 집에서 혼자서도 영어를 익히는 방식이에요" ·
    "온라인이라도 영어를 체계적으로 배우도록 프로그램이 짜여 있어요") — "무엇이다" 설명이 아니라
    사용자가 얻는 변화·판단 포인트·부담 완화·관리 가능성으로 끝낸다
  - **너무 안전해서 광고 매력이 약한 문장** — 형식·자연성 위반이 없어도 재작성 대상이다
  - title을 반복만 하는 문장(§title+copy 연결성과 동일)
- **copy 우선 반영 요소(0722 — 개별 copy의 최소 성분)**: 모든 copy에는 아래 5요소 중 **하나
  이상**이 드러나야 한다. 기능 설명만 있고 5요소가 모두 없으면 재작성한다. (0716 표현 유형
  6종은 그룹 내 **분포**(혼합) 기준, 이 5요소는 **copy 한 문장**의 최소 성분 기준 — 별개 검사다.)

| 요소 | 설명 |
|---|---|
| 해결 방향 | title 고민에 대한 답(§title+copy 연결성 고민 축 일치) |
| 판단 포인트 | 사용자가 선택할 때 확인해야 할 기준 |
| 이용자 효익 | 시간 절감·비용 부담 완화·관리 편의·상태 확인 등 |
| 행동 이유 | 왜 지금 체험/신청/확인해야 하는지 |
| 변화 기대 | 사용 후 기대할 수 있는 변화 |
- 개선 예시(0716 — 캐츠잉글리시 실측, 원칙은 광고주 불문):

| 설명형 title (나쁨) | 개선 title | 연결 copy |
|---|---|---|
| 캐츠잉글리시 온라인 학습의 장점 | 온라인 영어, 집에서도 잘 따라갈까요? | 학습기와 온라인 콘텐츠로 집에서도 매일 영어 흐름을 이어갈 수 있어요 |
| 가성비 좋은 초등 영어 공부법 | 영어학원비가 매달 부담된다면 | 학원식 커리큘럼을 집에서 경험하며 비용 부담을 낮춰볼 수 있어요 |
| 아이 실력 점검, 미루지 마세요 | 우리 아이 영어, 지금 어디쯤일까요? | 무료 레벨테스트로 현재 수준과 다음 학습 방향을 확인할 수 있어요 |
| 단어랑 문장, 앱으로 훈련해요 | 배운 단어, 며칠 뒤엔 가물가물 | 매일 짧게 반복하며 단어와 문장을 오래 기억하도록 도와줘요 |

- **퍼널 단계별 초점(개발요청서 v2 — context-expansion 퍼널 표 우측 열)**: 고민 자극→해결 방향→
  혜택/판단 포인트 구조는 같고, **무엇을 혜택·판단 포인트로 쓸지는 단계가 정한다** — 문제정의=문제
  해결 가능성·핵심 편익 / 제품발견=상품군과 주요 혜택 제안 / 비교검토=비교 기준·혜택 차이 /
  단일제품평가=핵심 혜택·조건·적합성 / 신청전환=신청 전 확인사항·행동 유도 / 사용도움=사용 조건·
  적용 방법. title 훅과 copy 우선 반영 요소 5종 선택을 그 단계의 **정보 요구 수준**에 맞춘다
  (예: 비교검토 copy에 이용 방법 설명을 넣으면 단계가 흐려진다).
  - **⑤신청전환과 ⑥사용도움은 다른 단계다** — ⑤는 핵심 행동(신청·가입·상담·구매)을 **실행할지
    판단**하는 자리라 신청 전 확인사항·행동 유도가 오고, ⑥은 이미 이용하는 사람이 **더 잘 쓰기
    위한** 사용 조건·적용 방법이 온다. 한 그룹에 섞지 마라(pipeline 경고 `funnel_stage_merged`).
  - **신청전환의 "행동 유도"는 CTA 상한과 충돌하지 않는다** — §메시지 다양성 "상한은 금지가
    아니다"(0720)·그룹당 1건 항상 허용(0827)에 따라 신청전환 그룹에는 행동유도형 종결 1건이
    자연스럽다. 상한을 지키려 이 단계의 행동 유도를 0건으로 만들지 마라.
- **경계 — 매력은 표현·구조로 만든다, 사실로 만들지 마라.** "안전한 문장 금지"는 사실성 면죄부가
  아니다: 미제공 혜택·과장·근거 승격으로 매력을 높이면 환각이다(§사실성이 항상 우선). 같은 사실을
  고민→해결→혜택 구조와 생생한 입말로 재배치하는 것이 매력 개선이다.
- **정보 공백을 안내문으로 메우지 마라(0720 실측 — 광고주 불문 일반 규칙)**: 가격·조건·대상 등
  쓸 사실이 입력에 없을 때 "공식 안내에 적혀 있어요"·"이용 안내에 정리돼 있어요"·"신청할 때
  안내해 드려요"류로 문장을 때우면 광고가 아니라 공지다 — 클릭할 이유가 사라진다. 같은 유형:
  title이 조건을 물었는데 copy가 "신청하면 알려준다"로 답하는 **순환 답변**, "알아두면 좋아요"처럼
  해결 없는 마무리, **방향 없는 비교**("지출이 달라져요" — 어느 쪽으로 얼마나?). 대응은 두 가지뿐 —
  ① 그 광고의 각도를 **입력에 있는 다른 사실로 전환**한다(조건이 없으면 체험 방식·구성·확인
  포인트 등 확보된 사실로), ② 전환할 사실도 없으면 **그 각도의 광고를 만들지 않는다**(수량은
  다른 축에서 채운다). 안내문형으로라도 채우는 것이 최악이다 — "사실성 때문에 이렇게밖에 못
  쓴다"와 "쓸 사실이 없다"를 구분하라: 후자는 카피 문제가 아니라 각도 선택 문제다.
- **셀프 체크(시간 규율):** 쓸 때의 기준이다 — 별도 검증 루프를 돌리지 마라. 반환 직전 자연성
  재독(1회)과 **같은 훑기에서** 설명형·정보형·정의문형 세트, title 고민 축에 copy가 답하지 않는
  세트(§title+copy 연결성 고민 축 일치·축 어긋남·기능 나열 확산), 5요소가 모두 없는 copy,
  직관성 약한 title, **자기 퍼널 단계의 초점에서 벗어난 세트**를 함께 잡아 재작성한다(pipeline §8-2·§6-3).
  신규 기계 검사·플래그 없음 — 의미 검수 항목이다.

## 메시지 다양성

- 같은 광고그룹 안에서도 카피는 서로 다른 메시지 각도(혜택/신뢰/공감/방법 제시 등)를 다뤄야 한다.
- **표현 유형 6종 혼합(0716)**: 동일 광고그룹 내 copy는 아래 유형이 섞이도록 생성한다 — 동일한 문장 구조·동일한 행동 유도 표현의 과도한 반복 금지:

| 유형 | 역할 |
|---|---|
| 고민해결형 | 사용자의 문제에 대한 해결 방향 제시 |
| 혜택체감형 | 사용자가 얻는 변화나 장점 강조 |
| 비교판단형 | 선택 기준이나 비교 포인트 제시 |
| 이용방법형 | 어떻게 시작하거나 활용하는지 안내 |
| 결과기대형 | 사용 후 기대할 수 있는 변화 제시 |
| 행동유도형 | 신청·체험·구매·상담 등 다음 행동 유도 — CTA 30% 상한(`copy_cta_ratio_30`)과 같은 축, **그룹당 1건은 항상 허용**(0827) |

- **문장 형식 혼합**: 질문형/공감형/정보형/혜택형/비교형을 섞는다 — 동일 광고그룹에서 한 형식만 반복 금지. 단, **질문형 copy는 title이 질문형이 아닐 때만** 쓴다(§title+copy 연결성 재질문 금지).
- **종결 형태 분산**: title은 질문형/명사형/조건형/공감형 등, copy는 **완결 문장 범위 안에서** 질문형/정보형/제안형/비교형/행동유도형/공감형 등으로 나눈다 — **명사형·조건형 종결은 title 전용**, copy에 쓰지 마라(§문장 자연성). `~하세요/~해보세요/~확인하세요/~합니다/~있습니다` 형태 과다 반복 금지.
- **상투 종결 변주(0716)**: 같은 가능·유도 표현이 그룹 안에서 반복되면 아래처럼 변주한다(변주 후에도 완결 문장·해요체/합니다체·자연성 3원칙 유지):

| 반복되기 쉬운 표현 | 개선 방향 |
|---|---|
| 확인할 수 있어요 | 먼저 보고 결정해요 / 기준을 잡아줘요 / 결과를 비교해요 |
| 체험할 수 있어요 | 먼저 써볼 수 있어요 / 직접 경험해요 / 사용해보고 판단해요 |
| 시작할 수 있어요 | 부담 없이 시작해요 / 지금 바로 이어가요 / 첫 단계를 잡아줘요 |
| 제공합니다 | 이용할 수 있어요 / 함께 구성돼요 / 한 번에 연결돼요 |
| 비교해보세요 | 차이를 살펴봐요 / 선택 기준을 잡아봐요 / 나에게 맞는 방식을 찾아요 |
- **CTA형 종결 30% 이하(기계 검사)**: 사용자 행동을 직접 유도하는 종결(확인해보세요·신청하세요·시작해보세요·비교해보세요·알아보세요 등)은 동일 광고그룹 카피의 **30% 이하** — validate가 `copy_cta_ratio_30` 규칙으로 경고를 낸다. **그룹당 1건은 비율과 무관하게 허용**(0827 실측: 그룹 광고가 3개면 1건=33%라 상한이 CTA를 구조적으로 0건 강제했다 — 검사는 2건부터 비율을 본다).
- **상한은 금지가 아니다(0720 실측)**: 30% 상한을 지키려 행동유도형을 **전 캠페인 0건**으로 만들지 마라(실측: 90건 중 CTA 종결 0건 — 과잉 교정, 0827 재실측 1/90도 같은 편중). 신청전환 단계 그룹에는 행동유도형 종결 1건이 자연스럽고, 이제 검사도 그 1건을 경고하지 않는다. 병합 후 표현 유형 6종 중 **전역 0건인 유형**이 있으면 편중으로 보고 점검한다(pipeline §8-4).
- title 종결 형태 예시 (구문형·명사형·조건형 허용 — 어느 형태든 §광고 매력도의 고민·질문·상황 우선 기준을 함께 적용):

| 종결 형태 | 예시 |
|---|---|
| 질문형 | 초등 영어, 어디서 시작해야 할까요? |
| 명사형 | 집에서 시작하는 초등 영어 루틴 |
| 조건형 | 아이 영어 수준이 궁금하다면 |
| 공감형 | 영어 시작이 막막한 부모님에게 |
| 결과형 | 매일 쌓이는 영어 학습 습관 |

- copy 종결 형태 예시 (전부 완결 문장형 — 명사구·조건절 종결 금지):

| 종결 형태 | 예시 |
|---|---|
| 질문형 | 아이 영어, 무료 레벨테스트로 시작해 볼까요? |
| 정보형 | 무료 레벨테스트로 아이 수준을 먼저 진단할 수 있어요 |
| 제안형 | 학원 대신 집에서 하는 홈러닝도 좋은 선택지예요 |
| 비교형 | 학원과 온라인 학습의 차이를 한눈에 비교해 드려요 |
| 행동유도형 | 아이에게 맞는 학습법을 확인해보세요 |
| 공감형 | 막막했던 영어 시작, 수준 진단부터 함께 잡아드려요 |

- Context Hints를 충분히 커버하도록 제목·카피 세트를 구성한다.
- 목표 수량을 채우려 동일 의미 문구를 **무표시로** 반복하지 마라. 확장 축이 목표에 못 미치면(pipeline §8-1 워닝) 초과분은 **명시적 로테이션 변형**으로 생성한다 — `generation_basis`에 `변형=로테이션`을 남기고 의미 중복 후보 검토의 우선 대상이 된다.
